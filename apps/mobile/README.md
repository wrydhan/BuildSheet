# CarStory Mobile

Expo app for CarStory. See the [root README](../../README.md) for setup and commands.

## Quick start

From the repo root:

```bash
pnpm install
pnpm dev
```

From this directory:

```bash
pnpm start
pnpm ios
pnpm android
pnpm web
```

App source lives in `src/app/` (Expo Router file-based routing).

## Environment

Create `.env` in this directory:

```
EXPO_PUBLIC_SUPABASE_URL=
EXPO_PUBLIC_SUPABASE_ANON_KEY=
EXPO_PUBLIC_WEB_URL=
```
